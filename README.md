# ⚡ Fuel Cell Project

The project focuses on the **automatic extraction** of literature data related to **oxygen reduction reaction catalysts** for **PEFCs** (Polymer Electrolyte Fuel Cells). The extracted data will be used to assist in material development and strategy formulation in **corporate R&D** activities.

---

## 🎯 **Project Goals**

- **🧪 Extract ORR Catalyst Information:** Automatically extract **oxygen reduction reaction (ORR) catalyst** information for **PEFCs**.
- **📌 Develop a Comprehensive Catalyst Database:** Create a method to extract and complete missing data on catalyst properties.
- **🚀 Achieve High Extraction Accuracy:** Process **250,000 articles** with an extraction accuracy target of **90%**.
- **💡 Predict Catalytic Activity:** Use machine learning techniques to develop prediction models for catalytic activity.

---

## 🔍 **Project Focus**

- **🎯 Key Focus:** Extract **ORR-related information** from research articles.
- **🔧 Application:** Structure the extracted data to contribute to **constructing predictive models** for catalytic activity.
